# Master Mind Plan

A minimalist, focused project planning and execution workspace. Capture future build ideas, define an achievable first version, break work down into milestones and scheduled tasks, and focus on one clear next action at a time.

## ✨ Features

- **Project Pipeline:** Track builds across *Idea*, *Planned*, *Active*, *Paused*, and *Completed* stages in both Board and Grid layouts.
- **Calendar Scheduling:** Drag-and-drop step planning across Month and Week views, with an Unscheduled stack tray.
- **Scope Discipline:** Keep first-version feature commitments separate from future raw ideas.
- **Step Breakdown:** Milestones, tasks, and actionable subtasks with automatic dependency and prerequisite validation.
- **Single Next Action:** Choose one ready focus step per project to dive right back into flow.
- **100% Private & Local:** Client-side local storage with automatic debounced saving, schema validation, and JSON backup export/import.
- **Responsive Dark UI:** Designed with high-contrast charcoal surfaces, clean typography, and mobile touch support.

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/aljus10/Master-Mind-Plan.git
cd Master-Mind-Plan

# Install dependencies
npm --prefix app install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Available Scripts

- `npm run dev` — Launch Vite development server
- `npm run build` — Build production bundle for Vercel / static hosting
- `npm test` — Run Vitest unit & domain test suite
